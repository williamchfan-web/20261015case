📋 如何填入資料

於左側「基準色輸入」點擊色票選擇器挑選喜愛的顏色，或直接手動輸入標準六碼 HEX 格式（如 #2563EB），並選擇對應風格即可。

🔍 核對正常結果

系統將自動產生五大色票（主色、背景、正文、邊框、強調色），點擊任一色票可複製對應色碼。右側卡片與對比度計數器會即時反映該配色的視覺可讀性。

⚠️ 測試例外與防護

若在文字框中輸入無效格式（如少於六碼或包含英文字母 G-Z），系統會顯示即時錯誤提示，並安全保留最近一次的合法色碼不被覆蓋。
